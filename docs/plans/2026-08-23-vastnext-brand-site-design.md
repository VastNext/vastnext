# VastNext 品牌站设计

日期：2026-08-23

## 目标

VastNext 官网首先建立母品牌认知，其次为已发布产品和开源项目导流。网站面向全球普通用户和独立开发者同行：普通用户应快速理解产品价值，独立开发者应能感受到一个持续构建、愿意开放成果的独立产品实验室。

首版成功标准：

- 访客在首屏理解 VastNext 是一个持续创造实用产品的独立未来产品实验室。
- 三个已发布产品和 GlanceMD 均有清晰、准确的外部入口。
- 英文与简体中文分别拥有可索引 URL。
- 桌面端与移动端均保持清晰、完整、可访问的体验。
- 网站可作为纯静态资源部署到 Cloudflare Pages。

## 品牌定位

定位：面向每个人的独立未来产品实验室。

英文主张：`Useful ideas, built for what's next.`

中文主张：`把有用的想法，带到下一个未来。`

Vast 表达辽阔、开放与“瀚海”，Next 表达下一步、下一代与未来。品牌不局限于 AI、开发者工具或某一种产品类型，而以持续探索和交付实用产品为核心。

## 品牌资产

Logo 使用开放的 V/N 几何航标：下方是一条微弧地平线，上方是向右上延伸的开放折线，同时表达 Vast、Next、方向和持续探索。图形标记应能脱离字标独立使用，并提供适合 favicon 的简化版本。

视觉方向命名为“明亮新界 Bright Frontier”：

- 暖白 `#F7F8F3`：页面基底，建立亲和、明亮的氛围。
- 深靛蓝 `#18235C`：品牌文字、主要按钮和可信度锚点。
- 电光蓝：技术、连接和 Vast Translator 的产品信号。
- 薄荷青：安全、轻盈和 Password Generator 的产品信号。
- 珊瑚橙：能量、探索和品牌点缀。
- 柔紫：发现、想象和 Findry AI 的产品信号。

英文展示字体采用 Space Grotesk，中文及长正文采用 Noto Sans SC。展示文字几何、紧凑，正文保持自然和高可读性。

视觉参考吸收 Figma 的大色块叙事、Miro 的多彩产品分区和 Stripe 的轻盈未来渐变，但不复制任何单一品牌的 Logo、字体、组件组合或页面结构。VastNext 的独有母题是“航标、轨道与新地平线”。

## 信息架构

首版为单页品牌官网，英文路径为 `/`，简体中文路径为 `/zh/`。

1. 顶部导航
   - Products
   - Open Source
   - About
   - GitHub
   - 语言切换
2. 首屏
   - 品牌主张和一句简短介绍
   - `Explore our products` 主按钮
   - `View on GitHub` 次按钮
   - 动态航标与探索轨道视觉
3. Made by VastNext
   - Findry AI：发现适合任务的精选 AI 工具
   - Password Generator：生成随机密码、易记密码和 PIN
   - Vast Translator：并行比较多个翻译引擎的结果
4. Open by default
   - 单独突出 GlanceMD
   - 展示 Windows、Rust + WebView2、MIT 和 GitHub 入口
5. On the horizon
   - Games
   - Utilities
   - 仅作为实验方向，不承诺产品名称或发布日期
6. About
   - 解释 Vast + Next 与“瀚海·未来”
   - 表达面向每个人构建实用产品的长期方向
7. 页脚
   - `hello@vastnext.com`
   - GitHub 组织链接
   - 隐私政策
   - 语言切换

## 页面表现

页面不采用重复的等宽 SaaS 卡片网格。首屏航标延伸出一条贯穿页面的探索轨道，把品牌叙事、产品、开源项目和未来方向串成连续浏览体验。

三个产品使用不等宽展台，并以各自的信号色区分。展台包含简化的真实界面缩影或原创界面示意，确保视觉内容与产品功能有关。GlanceMD 使用更具工程感的独立横向模块，避免与商业产品混在同一层级。

交互保持轻量：

- 航标和轨道做缓慢自主运动。
- 内容进入视口时分段显现。
- 产品展台悬停时仅做轻微位移、边框和色彩响应。
- 所有外部链接明确标识并在新窗口打开。
- 用户开启 `prefers-reduced-motion` 时，动画退化为静态。
- 不使用 WebGL 或重型动画库。

移动端将横向构图变为纵向探索轨道，产品展台单列排列，导航折叠，同时保留至少 44px 的触控目标。

## 多语言与内容

英文为默认语言，中文位于 `/zh/`。两种语言生成独立 HTML，不依赖客户端切换后才出现内容。页面提供：

- 相互对应的 `hreflang` 与 `x-default`
- 各语言独立的标题、描述和 Open Graph 文案
- 语言切换保持在对应页面
- sitemap 与 robots.txt

首版产品内容集中在类型化数据文件中维护，避免页面之间出现链接、状态和翻译漂移。

## 技术架构

- Astro
- TypeScript
- 原生 CSS
- 自制 SVG Logo 与装饰图形
- 纯静态构建输出
- Cloudflare Pages 部署目标

构建命令为 `npm run build`，输出目录为 `dist`。外部产品是否可用不由品牌站探测，品牌站只保证链接正确，避免引入服务端任务、超时和误报。

## SEO、隐私与可访问性

- 每种语言配置 canonical、description、Open Graph、Twitter Card 和结构化组织数据。
- 提供 sitemap、robots.txt、favicon 和社交分享图。
- 隐私政策说明品牌站不主动收集个人信息；外部产品遵循各自政策。
- 使用语义化标题、导航、列表与链接。
- 保证文字对比度、键盘焦点、跳过导航链接和合理的替代文字。
- 动画尊重减少动态效果偏好。

## 验证

- 单元测试验证产品链接、语言内容和页面元数据。
- 运行 Astro 类型检查和生产构建。
- 检查站内链接、生成路径和静态资源。
- 运行 Lighthouse 或等价的性能、SEO、最佳实践和可访问性检查。
- 分别截图检查桌面英文、桌面中文、移动英文和移动中文页面。

## 首版边界

首版不包含：

- CMS 或后台
- 博客
- 邮件订阅
- 社区系统
- 产品运行状态探测
- 公开路线图或发布日期
- 服务端 API

这些能力只有在出现明确运营需求后再引入。
