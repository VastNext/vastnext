# VastNext 图标方案

本目录保存 10 套可替换的 VastNext 图标方案。

- `01`：航线、地平线与航标，当前网站采用方案。
- `02`：交汇的新路径。
- `03`：轨道与上升路线。
- `04`：负空间 V 航标。
- `05`：三层瀚海波浪。
- `06`：连续 VN 字母路径。
- `07`：通往未来的拱门。
- `08`：活泼的三点星座。
- `09`：交织的 VN 色带。
- `10`：船帆、海浪与前进箭头。

每套方案同时提供：

- SVG：`320 × 320`，适合编辑和无损缩放。
- PNG：`1024 × 1024`，适合头像、应用图标和快速预览。
